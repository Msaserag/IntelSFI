# Intel SFI Training Utilization Dashboard

Interactive dashboard for the Intel® Skills for Innovation (SFI) program delivered on Classera.
Single self-contained page: data is embedded in index.html (participant names are never stored).

## Update the data
1. Open the site and click **Update data**.
2. Upload the latest Classera SFI enrollment export (.xlsx). Required columns: Course Title, Name, classera school group, Classera school country, Classera school, Certificates, Enrollment Date.
3. Check the preview, then click **Download updated dashboard** (saves index.html).
4. In this repo: Add file > Upload files > drop index.html > Commit. GitHub Pages refreshes in about a minute.

Logos (SFI, Intel) can be added the same way from the Update data panel.
